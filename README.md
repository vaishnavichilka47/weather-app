# Weather App 🌦️

A simple weather application built using **HTML, CSS, and JavaScript** that fetches weather data from an API and displays it for the user.

## Features

* Search weather by city
* Displays current temperature
* Shows weather conditions
* Fetches real-time data using an API
* Simple and responsive interface

## Technologies Used

* HTML
* CSS
* JavaScript
* Weather API
